🔑 Configurar publicación automática (una sola vez) —
Publica docs/catalogo.html directo en tu GitHub Pages sin tocar archivos ni git — el link para tus clientes es siempre agustincrov.github.io/calculadora-importacion-perfumes/catalogo.html. Necesita que tu Cloudflare Worker (comparapi-proxy) tenga configuradas dos variables secretas (Settings → Variables): GITHUB_TOKEN (fine-grained PAT, permiso de escritura solo en este repo) y PUBLISH_SECRET (cualquier clave larga random — pegá la misma acá abajo).
💡 Si preferís hacerlo a mano: "Descargar página buscable" siempre descarga catalogo.html (mismo nombre) — movelo a docs/catalogo.html en la carpeta del repo (reemplazando el anterior), git add docs/catalogo.html && git commit -m "catálogo" && git push, y compartí el mismo link de arriba. — así en WhatsApp les abre directo en el navegador (a diferencia de mandar el archivo suelto, que en iPhone no siempre abre bien).
